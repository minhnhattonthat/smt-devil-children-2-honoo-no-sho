Shin Megami Tensei: DemiKids - Book of Fire (Devil Children 2 Honoo no Sho, GBA)
English translation patch, version 1.2
==========================================================================

What it is
----------
A complete English translation of "Shin Megami Tensei: Devil Children - Honoo no Sho"
(Atlus, 2003, Game Boy Advance). All dialogue, menus, battle text, item / skill / demon
names and descriptions, the DemiDex, the staff roll and the title logo are in English.

The patch expands the ROM to 16 MiB and adds a variable-width font. Saves are battery
(SRAM) saves, as in the original.

How to apply
------------
1. Get the ROM below. It must match these hashes:

     Shin Megami Tensei - Devil Children - Honoo no Sho (Japan).gba
     Size   8,388,608 bytes (8 MiB), header DEBITIRUFLAMB
     CRC32  9A0903BC
     MD5    6207cb2c18a77cc408c6e42cc7f0cf10
     SHA-1  8c29d6921e7db8b0e71094d32e32066ac13c500d

2. Apply the .bps patch with Flips, beat or https://www.marcrobledo.com/RomPatcher.js/
3. Play the patched .gba in any GBA emulator or on a flash cart.

Patched ROM: 16,777,216 bytes, SHA-1 {OUT_SHA1}

Names and terms
---------------
Demon names follow the official English Shin Megami Tensei / DemiKids spellings where they
exist. In-game terms follow the official DemiKids localization (DemiKid, Demiloc, DemiDex,
Macca). Japanese honorifics are dropped; names are given name first.

The kana grid of the name-entry screen stays Japanese on purpose (it is the input character
set); its ABC page is English and the default names are Jin and Rand.

Known limits
------------
- A few labels drawn in tiny fixed boxes use short forms: the item tabs (HEAL, FIGHT, BOOST,
  OTHER, GEAR, FOSSIL) and the name-entry page buttons (Hira, Kata).
- Some place names on fixed-width labels are shortened slightly.
- On the Settings screen the cursor highlight keeps the width of the Japanese word, so it
  covers some English labels only partly.
- Menus were tested up to the mid game; a picture-drawn label on a late-game screen may still
  be Japanese.
